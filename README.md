# 思维导图编辑器（honx_map）

基于 [jsMind](https://github.com/hizzgdev/jsmind) 的纯前端网页版思维导图创建工具，无需后端。

## 功能

- ↩️ 撤销 / 重做：编辑历史快照（最多 50 步），按钮或快捷键 Ctrl+Z / Ctrl+Y（或 Ctrl+Shift+Z）；覆盖节点增删改、移动、连线等所有编辑操作
- ✏️ 可视化编辑思维导图（添加/编辑/删除节点、拖拽视图、缩放、展开/收起）；展开/收起按钮（expander）按节点方向定位——左侧分支在节点左缘、右侧分支在右缘，拖动节点后跟随
- 📋 左侧大纲结构面板：实时显示导图层级，支持重命名、添加、删除节点，以及升级（⇤ / Shift+Tab）、降级（⇥ / Tab）节点，与画布选中双向联动，可通过工具栏「📋 大纲」显隐
- 🖱️ 节点拖拽调整位置：鼠标拖动节点到目标节点上即可改变层级/顺序（jsMind draggable_node 插件）；**按住 Alt 拖动节点**则自由移动位置，其子树和所有连线整体跟随（偏移持久化，刷新后保持）；**Alt + 拖动中心主题（根节点）可整体移动整个导图**，所有节点、树形连线和流程连线同步平移
- ⬚ 区域框选与整体移动：**按住 Ctrl/Alt + 鼠标左键划过区域**框选多个节点和连线（选中项高亮），随后**直接拖动其中任一选中节点**即可整体移动所选区域；移动过程中树形连线和流程连线实时跟随，位置偏移持久化（刷新后保持），支持撤销/重做；Esc 或点击空白处取消区域选择
- 🧩 自动排版：工具栏按钮或画布右键菜单触发，重新布局防止节点重叠
- 🔀 流程图能力（有向流程图创建）：
  - ➡️ 有向箭头连线：连线模式下点击源节点再点目标节点，绘制带箭头的有向连线
  - 🖱️ 鼠标拖拽连线：连线模式下按住源节点拖动到目标节点松开即连线（带虚线预览）
  - — 直线连线 / ↻ 循环（自环）连线：支持节点自指循环
  - ◈ 接头节点：可自由拖动的独立小圆点（22×22），作为多条连线的中间/交汇节点
  - ⭕ 独立节点：不挂在树下的自由节点，可用鼠标拖到任意位置，再用连线与其他节点连接；支持添加子节点，子节点相对独立节点排列并随其拖动整体跟随（记录相对偏移，刷新后保持）
  - 连线可点击选中，弹出面板调整：类型（箭头/直线/循环）、形状（曲线/直线/肘形）、弧度（滑块，正值/负值改变弯曲方向以避开节点遮挡）、颜色，或删除
  - **树形连线（父子连线）也可点击选中**：选中后高亮加粗，面板可改颜色（自定义颜色持久化保存，刷新保持）；「删除」会把子节点脱离父节点转为独立节点（树形连线无类型/形状选项）
  - 节点删除时自动清理相关连线；节点收起隐藏时连线自动隐藏，展开恢复
  - 连线与独立节点位置随导图持久化保存、刷新恢复，并包含在 PNG/PDF 导出中
  - 画布右键菜单支持「连接到…」「自环」「转为子节点」（仅独立节点可用，脱离自由状态挂回树布局）、「展开」「收起」（仅有子节点时可用，按当前状态启用）快捷操作
  - 独立节点在整图（根节点）移动时不随之移动、不自动建立到主节点的连线（自由体系独立）；框选包含独立节点时则随选区整体移动

## 工具栏布局

工具栏按功能分为 6 组：**面板与历史**（大纲/属性面板显隐、撤销/重做，位于最左端）、模式（选择/连线）、节点（子节点/同级/独立/接头/编辑/删除）、连线类型、视图（缩放/展开收起/排版）、文件（打开/保存）、导出（图片/PDF/Word）。
- 📄 页面属性面板：点击画布空白处显示，支持调整导图名称、画布尺寸（宽×高）、页面背景色、导出图片/PDF 背景色，均持久化保存
- 🎛️ 右侧节点属性面板：选中节点后自动同步并回显当前属性，可编辑
  - 节点大小（宽 × 高，留空自适应）
  - 外框形状（默认 / 方形 / 圆角 / 胶囊 / 圆形 / 菱形 / 三角 / 底线）
  - 背景色与文字色
  - 文字对齐：水平（左/居中/右）+ 垂直（上/居中/下），共 9 种组合
  - 换行方式：自动换行 / 手动换行（编辑器支持回车换行，Ctrl+Enter 提交，换行符保留渲染）
  - 插入表情图标（本地表情库，分 13 类共 700+ 个：笑脸/手势/标记/物品/自然/动物/食物/活动运动/旅行交通/符号/商务标签/人物/旗帜）
  - 插入/移除用户图片（作为节点背景图，自动缩放）
  - 可通过工具栏「🎛️ 属性」按钮显隐；面板显示选中节点的主题、大小、形状、颜色等持久化状态
- 💾 保存到本地：弹出格式选择框——**明文 `.jm`（JSON）** 或 **加密 `.hxmp`**（AES-GCM 加密，PBKDF2 派生密钥，需设置密码）；同时自动保存到浏览器 localStorage，刷新不丢失
- 📂 打开本地 `.jm` / `.json` / `.hxmp` 导图文件；打开 `.hxmp` 加密文件时弹出密码框，密码错误提示并可重试
- 🖼️ 导出 PNG 图片（jsMind 截图插件）
- 📄 导出 PDF（截图 + jsPDF，自动适配 A4 纸张方向）
- 📝 导出 Word（.doc，以大纲层级列表形式呈现）

## 运行方式

所有依赖均已本地化到 `vendor/` 目录，无需联网。启动本地静态服务器：

```bash
cd honx_map
python3 -m http.server 8000
```

然后浏览器访问 <http://localhost:8000>。

> 直接双击 `index.html`（file:// 协议）也能正常运行。

## 快捷键

| 快捷键 | 功能 |
| ------ | ---- |
| Insert | 添加子节点 |
| Enter  | 添加同级节点 |
| F2 / 双击节点 | 编辑节点 |
| Delete | 删除选中节点 |
| 方向键 | 切换选中节点 |
| 空格 | 展开/收起节点 |

## 文件结构

- [index.html](index.html) — 页面结构
- [app.js](app.js) — 编辑器逻辑（节点操作、保存、导出、属性面板、拖拽）
- [style.css](style.css) — 界面样式（含节点形状样式）
- [vendor/](vendor) — 本地化的第三方依赖库
- [emoji/catalog.json](emoji/catalog.json) — 本地表情图库（可自由扩充）

## 依赖（已本地化到 vendor/）

- jsmind 0.9.1（含 screenshot、draggable_node 插件）
- dom-to-image 2.6.0（截图插件依赖）
- jspdf 2.5.1（PDF 导出）

所有依赖均已下载到本地 `vendor/` 目录，完全离线可用。表情图库位于 `emoji/catalog.json`，可按分类自由增删。
